راهنمای راه‌اندازی «تغییرات مدیر برای همه» + اثر انگشت/چهره
=============================================================

چرا لازم است؟
-------------
سایت بدون سرور همه‌چیز را فقط داخل مرورگر همان دستگاه ذخیره می‌کند؛ پس تغییرهای مدیر فقط برای خود مدیر دیده می‌شود.
این نسخه یک لایهٔ «ابر» دارد (Firebase Realtime Database، رایگان). بعد از راه‌اندازی:
- جنس، عکس، بنر، لوگو، ویدیو و پلن‌هایی که مدیر تغییر می‌دهد برای همه دیده می‌شود (حدود هر ۸ ثانیه به‌روز می‌شود).
- جنس‌هایی که فروشنده‌ها آپلود می‌کنند برای همه مشتری‌ها دیده می‌شود.
- وقتی مدیر پلن فروشنده را فعال می‌کند، در گوشی فروشنده هم فعال می‌شود.
- «ریست دیتابیس» اطلاعات ابر را هم پاک می‌کند.
اگر هیچ‌کاری نکنید، سایت مثل قبل و فقط روی همان دستگاه کار می‌کند.

مرحله ۱ - ساخت دیتابیس (۵ دقیقه)
--------------------------------
۱) به console.firebase.google.com بروید و با حساب گوگل وارد شوید.
۲) Add project (یا Create a project) بزنید، یک اسم بدهید (مثلاً azimi-store)؛ Google Analytics را خاموش کنید.
۳) در منوی سمت چپ: Build > Realtime Database > Create Database. موقعیت سرور را انتخاب کنید و حالت Test mode (یا باز) را بزنید.
۴) بالای صفحهٔ Data یک آدرس می‌بینید، شبیه:
      https://azimi-store-default-rtdb.firebaseio.com
   (یا ...firebasedatabase.app). آن را کپی کنید.
۵) تب Rules را باز کنید و این را بگذارید و Publish بزنید:
      { "rules": { ".read": true, ".write": true } }
(اسم دکمه‌ها ممکن است کمی فرق کند؛ Firebase گاهی ظاهرش را عوض می‌کند.)

مرحله ۲ - وارد کردن آدرس در سایت
-------------------------------
فایل config.js را با Notepad باز کنید و آدرس را بین نقل‌قول‌ها بگذارید:
      window.AZ_CLOUD = { url: 'https://azimi-store-default-rtdb.firebaseio.com' };
ذخیره کنید.

مرحله ۳ - بالا بردن سایت روی اینترنت (https)
--------------------------------------------
کل پوشه (index.html، config.js، logo.png، icons، manifest.webmanifest ...) را روی یک هاستینگ بگذارید. ساده‌ترین راه:
- app.netlify.com/drop : پوشه را بکشید و رها کنید، یک لینک https می‌دهد.
- یا GitHub Pages / Cloudflare Pages.
روی هاستینگ هم اثر انگشت/چهره کار می‌کند (فقط روی https یا localhost کار می‌کند، نه از فایل لوکال و نه از http).

مرحله ۴ - اولین بار (فقط مدیر)
------------------------------
۱) سایت را با همان مرورگری که قبلاً اطلاعات را در آن ساخته‌اید باز کنید.
   اگر ابر خالی باشد، اطلاعات همان دستگاه خودکار به ابر آپلود می‌شود.
۲) وارد «پنل مدیریت» شوید؛ بخش «همگام‌سازی ابری» باید «متصل است» را نشان بدهد.
۳) از این به بعد هر دستگاه تازه‌ای که سایت را باز کند، اطلاعات را از ابر می‌گیرد.
نکته: وقتی ابر روشن است، جنس‌های نمونهٔ اولیه دیگر خودکار ساخته نمی‌شوند.

محدودیت‌ها و امنیت (مهم)
------------------------
- رمز پنل مدیریت داخل کد سایت است و قاعدهٔ باز بالا به هر کسی که آدرس دیتابیس را بداند اجازهٔ نوشتن می‌دهد. برای شروع و آزمایش خوب است؛ برای فروش جدی بعداً باید ورود واقعی (Firebase Authentication) یا یک سرور اضافه شود.
- شمارهٔ تلفن و آدرس مشتری‌ها در ابر ذخیره نمی‌شود (فقط در پیام واتساپ می‌رود)؛ ابر فقط نام، ولایت و اجناس سفارش را نگه می‌دارد.
- عکس‌ها داخل خود دیتابیس ذخیره می‌شوند و هر بازدیدکننده همه را دانلود می‌کند. برای چند ده جنس مشکلی ندارد؛ برای فروشگاه بزرگ باید عکس‌ها به یک سرویس ذخیرهٔ عکس منتقل شوند.
- ورود به حساب (لاگین) هنوز وجود ندارد: حساب فروشنده روی همان گوشی که ساخته شده می‌ماند.

اثر انگشت / چهره
-----------------
- فقط روی https یا localhost کار می‌کند. اگر پیام خطا می‌دهد، یعنی سایت از فایل لوکال یا از http باز شده.
- گوشی یا ویندوز باید قفل صفحه داشته باشد (اثر انگشت، چهره، یا Windows Hello).
- روی ویندوز: Windows Hello (PIN/اثر انگشت/چهره) را در Settings > Accounts > Sign-in options فعال کنید.
